# 提问检查与澄清 · 使用说明

这个技能面向刚开始用 AI 的人。装好后，照平常说话的方式提问即可，比如「帮我看看」「这个怎么样」「选哪个好」「写个通知」「按刚才那个来」。

它会这样帮你：
- **问得太宽泛或疑似笔误说反**：在**开头**先把更具体、清晰的问法亮出来再回答，让你第一眼就能核对方向对不对。
- **信息没说全**：语气、篇幅等先按常见做法给你一版，末尾用一句话说明可改哪里；具体时间、地点、金额等事实留 `[待填]` 提醒你补，不会瞎编。
- **选错会白做或有外发风险**：默认只问一个最关键的问题（复杂任务最多把 2～3 个独立问题合并列出），均附选项和推荐答案。普通任务你回「随便」或漏答某项就按推荐推进；涉及外发、删除、覆盖等动作则必须等你明确确认。
- **涉及原因、动机、预测或选哪个好**：不顺着话头瞎猜，会把事实、成立条件、不同优先级下的取舍讲清楚。
- **AI 看不到或看不清你说的东西**：直接告诉你，并说明怎么把内容给它。
- **下次可以这样说**：在写材料、分析、沟通等可复用任务需要追问或补默认信息时，末尾附一句示范说法（开头已示范过新问法或日常随口问答时不打扰；说「不用提示」即可关闭）。

## 安装

- **Claude**　在支持自定义技能的账户中，进入 Customize → Skills，上传整个 ZIP，确认已启用。[Claude 官方说明](https://support.claude.com/en/articles/12512180-use-skills-in-claude)
- **Codex**　解压 ZIP，把 `question-preflight` 文件夹放入 `~/.agents/skills/`（所有项目可用）或项目的 `.agents/skills/`（只在该项目）。最终路径应为 `.agents/skills/question-preflight/SKILL.md`。列表没刷新就重启 Codex。[Codex 官方说明](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)
- **其他客户端**　先确认支持导入自定义 Agent Skills，再按客户端入口导入。是否在某一轮调用由客户端决定。[Agent Skills 规范](https://agentskills.io/specification)

## 装好后可以这样试

每个例子单独开一段对话。客户端如果能显示调用记录，可以确认技能是否真的被调用——回答符合预期，不代表一定调用了技能。

| 场景 | 先给的背景 | 接着提问 | 希望看到的行为 |
| --- | --- | --- | --- |
| 撰写报告 | 无 | 「帮我写份本月工作总结」 | 直接给一版（缺具体数据处留 `[待填]`），末尾附默认值说明和「下次可以这样说」 |
| 客户 / 供应商沟通 | 贴一段发给供应商的催货消息 | 「这个怎么样？」 | **开头**先亮出聚焦后的具体问法（如语气、截止时间是否清楚），再直接评估 |
| 咨询与方案选型 | 无 | 「做小程序选模板还是定制开发好？」 | 点明取决于预算、上线速度还是个性化需求，按优先级给出对应推荐 |
| PPT / 复杂方案 | 无 | 「帮我做一套客户招采汇报方案」 | 把最关键的 2～3 个独立问题（受众、核心指标、形式）合并列出并附推荐默认 |
| 材料交接 | 「给供应商的是分批供货版，给内部同事的是轮班验货版。」 | 「把那个同步给小王。」 | 只问同步哪一版，未确认前不乱发 |
| 提供服务 | AI 问你是先安抚给新时间，还是给补偿方案 | 「你看着办」 | 按推荐默认值直接写出回复稿，不再反复追问 |
| 简单数据分析 | 「换话术后成交从 30 单涨到 36 单。」 | 「所以新话术带来了 6 单，下月还能涨吧？」 | 给出 +6 单/+20%，拆开事实与缺口证据，并说明下月预测依赖的条件 |
| 材料缺失 | 无 | 「帮我看看这份合同」（未附文件） | 说明看不到，告诉你怎么粘贴或上传，不瞎猜 |
| 清晰请求 | 无 | 「把‘周四下午三点开会’翻成英语，只给译文。」 | 直接给译文，不复述题目、不加提示 |

## 让它适应你

你可以用自己的话定义口头禅：

> 以后我发稿子说「帮我看看」，请只指出最影响读者理解的一处，保留原文。

遇到例外就说「这次直接帮我改」。客户端有私人偏好存储、且你同意时，AI 才会跨对话保存；否则可以请它「把这条习惯整理成一句我能带走的话」，换对话时再贴入。

## 隐私

技能包本身只是文字说明，没有任何回传对话或偏好给作者的功能。客户端如何保存数据，取决于该产品和你的设置。
